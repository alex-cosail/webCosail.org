## 1. Зачем

cosail.org делался за несколько часов как ссылка на программу. Новый сайт — **витрина программы NavCoSail**:
- показать, что умеет программа, простыми словами для яхтсмена;
- показать школам учебный модуль: живая учебная задача в окне прямо на странице;
- связать с Cosail (мероприятия — на alex-cosail.com);
- показывать, что программа живёт и развивается (список версий).

## 3. Главная страница — блоки сверху вниз

Тексты ниже — смысл (слова Алексея); окончательные формулировки на трёх языках — в партии Б, на согласование.

**0. Шапка.** Логотип CoSail / NavCoSail, якоря на блоки, переключатель EN / RU / TR, кнопка **«Открыть программу»** → `https://nav.cosail.org`.

**1. Hero.** Заголовок: **«Настоящие карты и навигационные инструменты — у вас в кармане»**. Кнопка «Открыть программу», картинка — экран программы (ПК + телефон).

**2. Блоки о программе** (картинка/скриншот + 2–3 строки текста + ссылка «попробовать»):
- **2.1. Маршрут за несколько кликов** — прикинуть маршрут сразу на экране приветствия (Fast Route).
- **2.2. Полная картина перехода** — Passage Plan; поделиться с командой, перенести в навигатор или вести яхту со смартфона (в мобильной версии приложения).
- **2.3. Нет нужной подписки?** — в приложении можно использовать бумажную карту со штурманского стола (сфотографировать → привязать → работать).

**3. Заключительный блок о программе — QR.** «У вас есть план идеального маршрута на неделю? Просто разместите его в виде QR-кода на своей страничке!» Пример: QR демонстрационного маршрута (сканируется телефоном и открывает маршрут в программе) + три шага «Построить → Поделиться → QR». ## 4. Блок «Для школ» — задача в окне

Что нужно от программы (режим `embed`, рамка для любого сайта) — ТЗ программы `navcosailClaude/docs/TZ_Cosail_Org_Site.md` §5, сделано в 0.9.3-beta.47.

### 4.1. Что видит посетитель

- Заголовок и посыл школам (Р4).
- **Окно с программой** — опубликованная демонстрационная задача (`?t=<taskId>&embed=1`; пока — уже опубликованная `2a02a0d7-18b8-4e44-816e-bdf6b4079635`, Алексей готовит более красочную — id меняется в одном месте, файл данных сайта), решается прямо на странице: строить, отвечать, задать вопрос — всё как по обычной ссылке.
- Под окном — кнопки **«На весь экран»** (сайт разворачивает само окно, `iframe.requestFullscreen()`) и **«Открыть в новой вкладке»** (обычная ссылка задачи без `embed`).
- Рядом — «Задания могут быть любыми» и «Встраивание в ваш сайт или учебную платформу — одна строка кода» (формулировка Алексея 17.11.2026 — корректно: строка работает там, где можно вставить HTML; где только ссылки — по ссылке) и сама строка (копируется кнопкой):
  ```html
  <iframe src="https://nav.cosail.org/?t=2a02a0d7-18b8-4e44-816e-bdf6b4079635&embed=1" width="100%" height="640" allow="fullscreen; clipboard-write"></iframe>
  ```
  и примечание мелко: «Подходит для Moodle и любой платформы, где можно вставить HTML. Где можно дать только ссылку — задача откроется по ссылке.»; в тексте карточки — «учебную карту для вашей школы подготовим по запросу» (Р5).

### 4.2. Размер окна

- ПК: ширина колонки сайта, высота ≈ 75 % высоты экрана (не меньше 560 px). Узкое окно программа сама показывает телефонной раскладкой (работает с партии 6).
- Телефон: окно на всю ширину, высота ≈ 80 % экрана; решать удобнее на весь экран — над окном подсказка «Нажмите „На весь экран“».
- Подгонка высоты по сообщению от программы (postMessage) — **не делаем в первом выпуске**: у программы нет «естественной» высоты, она заполняет любое окно.

## 5. Версии и новшества

- Список: номер версии, дата, 1–3 строки «что нового» простыми словами (не технический журнал), три языка.
- **Только значимые версии — где полностью реализована какая-либо функция программы, 5–6 шагов назад** (решение Алексея 17.11.2026): учебный модуль (beta.46), векторный слой (beta.36), бумажные карты (beta.27), быстрый маршрут (beta.11), вход и регистрация (beta.4), изобаты Бодрум — Анталья (beta.1). Новая запись — когда следующая функция закончена и выпущена; если записей станет больше 6, старые уходят под «Все версии».
- Источник: файл данных в репозитории сайта (`src/data/versions.ts`); первые записи Claude соберёт по итогам дней программы (`navcosailClaude/docs/archive/SUMMARY_*.md`), дальше — запись добавляется вместе с релизом программы (В4).

- Репозиторий сайта (проверено 17.11.2026): локальная копия `C:\projects\webcosailorg`; ветки **`main` — рабочая**, **`public` — публичная** (Cloudflare собирает сайт из `public`). Ветка `main` от 27.09.2026 совпадает с выгрузкой AI Studio `C:\projects\cosail_org\20260927` — это и есть текущий сайт; папка `cosail_org` и zip-архивы больше не нужны.
- Порядок работы как на alex-cosail.com: правки — в `main`, выкладка — слияние `main` → `public`. Обе ветки держим всегда.
- Новый сайт на Astro кладётся в этот же репозиторий, код AI Studio удаляется (останется в истории git).
- Документация сайта — `docs/` этого репозитория (этот файл; дальше — `docs/backlog.md`). Встраивание в программу — в репозитории программы.
- По образцу alex-cosail.com: папки `inbox/` и `Claude outputs/` (в .gitignore, добавлены 17.11.2026), медиа — `public/media`, адреса с `/` на конце, `/ru/`, `/tr/`, 404 → главная на языке посетителя.
- Cloudflare: сайт выложен как Worker `webcosail-org` (`wrangler.toml`, статика из `dist`). Astro собирается в `dist` так же; перед партией Г — сверить команду сборки в настройках Cloudflare (`npm run build`) и версию Node.
